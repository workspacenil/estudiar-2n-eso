# Estadística Interactiva: Paràmetres de Centralització i Gràfics

Aplicació web interactiva i pedagògica en català per a l'estudi de la **Moda**, **Mediana** i **Mitjana Aritmètica**, acompanyada de representacions visuals mitjançant **Diagrama de Barres** i **Diagrama de Sectors**.

## 🚀 Característiques

- **Resolució interactiva completa dels exercicis:**
  - **Apartat a:** Marques de cotxes en un taller (Variable qualitativa nominal).
  - **Apartat b:** Edats de nois i noies (Variable quantitativa discreta).
  - **Apartat c:** Nombre d'assignatures suspeses el segon trimestre (Variable quantitativa discreta).
- **Simulador Pas a Pas:** Visualitza com s'ordenen les dades, com es troben les posicions centrals i el càlcul matemàtic de la mitjana.
- **Taula de freqüències completa:** Amb freqüències absolutes ($f_i$), relatives ($h_i$), percentatges ($\%$) i càlcul d'angles ($\alpha^\circ = \frac{f_i}{N} \cdot 360^\circ$).
- **Gràfics dinàmics (Chart.js):** Diagrama de barres animat i diagrama de sectors interactiu.
- **Laboratori Virtual:** Introdueix les teves pròpies dades per calcular tots els paràmetres i dibuixar els gràfics en temps real.
- **Test d'Autoavaluació:** 4 preguntes clau amb correcció immediata i confeti.

## 💻 Com utilitzar-ho

1. Clona o descarrega aquest repositori.
2. Obre directament el fitxer `index.html` amb qualsevol navegador web (Chrome, Firefox, Safari, Edge).
3. No cal instal·lar dependències, funciona directament al navegador.
